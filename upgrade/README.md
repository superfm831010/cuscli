## 🚀 快速开始

### 升级前准备

1. **阅读主计划**
   ```bash
   cat upgrade/upgrade-plan-2.0.2.md
   ```

2. **了解技术细节**
   ```bash
   cat upgrade/research-report.md
   ```

3. **评估风险**
   ```bash
   cat upgrade/risk-mitigation.md
   ```

4. **准备检查清单**
   ```bash
   cp upgrade/checklist.md upgrade/checklist-working.md
   # 在 checklist-working.md 中记录进度
   ```

### 执行升级

**按照以下顺序操作**：

1. 打开检查清单 `checklist.md`
2. 参考主计划 `upgrade-plan-2.0.2.md`
3. 逐项执行并勾选
4. 遇到问题参考 `risk-mitigation.md`

### 升级后

1. 在 `docs/二次开发记录.md` 中记录升级过程
2. 填写 `checklist.md` 中的总结部分
3. 填写 `risk-mitigation.md` 中的经验教训

## 🔄 推荐执行策略

### 方案：渐进式激进迁移

**策略**: 完全采用 2.0.2 的 terminal 架构，但保留所有自定义功能

**优势**:
- ✅ 插件兼容性极好，迁移成本低
- ✅ 新架构设计优良，长期价值高
- ✅ 可以获得所有新功能
- ✅ 风险可控（有完整的回滚方案）

**执行建议**:
- 分两天执行
- 第一天：阶段 1-6（准备、备份、代码替换、适配）
- 第二天：阶段 7-10（测试、文档、打包、提交）
- 每个阶段完成后立即验证

## 🆘 问题处理

### 遇到问题时

1. **查看风险管理文档**
   ```bash
   grep -A 10 "风险 X" upgrade/risk-mitigation.md
   ```

2. **查看缓解措施**
   - 每个风险都有详细的缓解措施
   - 按照应急方案操作

3. **考虑回滚**
   - 参考 `risk-mitigation.md` 中的回滚方案
   - 评估是否满足回滚触发条件

### 回滚流程

```bash
# 完整回滚到 1.0.39
git checkout main
git checkout v1.0.39-custom-backup-$(date +%Y%m%d)
pip uninstall cuscli -y
pip install -e .
```
