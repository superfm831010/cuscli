# 后端日志规范

## 规则条款

### 1. 日志级别规范

- **backend_037**: 注意日志输出级别，区分INFO、WARN、DEBUG、ERROR
- 来源：backend_rules修订版.xlsx 第36行
- 说明：正确使用日志级别，便于问题定位和日志过滤

### 2. 日志内容准确精简

- **backend_038**: 日志输出信息要准确、精简，方便定位，避免输出过多无用内容
- 来源：backend_rules修订版.xlsx 第37行
- 说明：有效的日志应包含关键信息，避免冗余

### 3. DEBUG日志补充

- **backend_039**: 复杂业务逻辑处理要为排查问题补充debug级别日志
- 来源：backend_rules修订版.xlsx 第38行
- 说明：调试日志有助于开发和测试阶段的问题排查

## 适用场景

本规则适用于所有后端日志记录场景，确保日志信息完整、清晰、易于问题定位。
