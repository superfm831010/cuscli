## 1. 概述

### 1.1 手册目的

本手册旨在为Auto-Coder AI代码检查系统的运维人员提供全面的运维管理指南，确保系统稳定、高效、安全地运行。

**主要目标：**
- 规范日常运维操作流程
- 建立系统监控与预警机制
- 确保数据安全与业务连续性
- 提升运维效率和服务质量
- 降低系统故障风险

### 1.2 适用范围

**适用人员：**
- 系统运维工程师
- 技术支持人员
- 系统管理员
- 应急响应团队

**适用场景：**
- 日常系统维护
- 故障处理与应急响应
- 系统升级与变更
- 性能优化与调优
- 安全管理与审计

### 1.3 运维目标

| 指标类别 | 目标值 | 说明 |
|---------|--------|------|
| **系统可用性** | ≥99.5% | 月度统计，排除计划维护时间 |
| **平均故障响应时间** | ≤15分钟 | 紧急故障 |
| **平均故障恢复时间** | ≤2小时 | 一般故障 |
| **备份成功率** | 100% | 每日自动备份 |
| **监控覆盖率** | 100% | 核心组件和服务 |
| **安全事件响应** | ≤30分钟 | 重大安全事件 |

## 3. 日常运维操作

### 3.1 系统巡检

#### 3.1.1 每日巡检清单

**时间：** 每日上午10:00

**检查项目：**

1. **系统运行状态**
   ```bash
   # 检查系统进程
   ps aux | grep auto-coder
   ps aux | grep byzerllm

   # 检查服务状态
   systemctl status auto-coder

   # 检查系统负载
   uptime
   top -bn1 | head -20
   ```

2. **资源使用情况**
   ```bash
   # CPU使用率
   mpstat 1 5

   # 内存使用
   free -h

   # 磁盘空间
   df -h

   # 磁盘IO
   iostat -x 1 5
   ```

3. **网络连接**
   ```bash
   # 网络连接数
   netstat -an | grep ESTABLISHED | wc -l

   # 端口监听
   netstat -tlnp | grep auto-coder

   # 网络流量
   iftop -t -s 10
   ```

4. **日志检查**
   ```bash
   # 检查错误日志
   tail -100 /home/$(whoami)/.auto-coder/logs/auto-coder.log | grep ERROR

   # 检查系统日志
   journalctl -u auto-coder -n 50 --no-pager
   ```

5. **数据库连接**（如使用）
   ```bash
   # 检查数据库连接
   # 根据实际数据库类型调整
   ```

**巡检记录表：**

| 检查项 | 状态 | 异常说明 | 处理措施 | 检查人 |
|-------|------|----------|----------|--------|
| 系统进程 | ☑ 正常 / ☐ 异常 | | | |
| CPU使用率 | ☑ 正常 / ☐ 异常 | | | |
| 内存使用 | ☑ 正常 / ☐ 异常 | | | |
| 磁盘空间 | ☑ 正常 / ☐ 异常 | | | |
| 网络连接 | ☑ 正常 / ☐ 异常 | | | |
| 应用日志 | ☑ 正常 / ☐ 异常 | | | |

#### 3.1.2 每周巡检清单

**时间：** 每周一上午

**检查项目：**

1. **系统更新检查**
   ```bash
   # Ubuntu/Debian
   ```

4. **备份验证**

### 3.2 服务启停管理

#### 3.2.1 服务启动

**标准启动流程：**

1. **前置检查**
   ```bash
   # 检查依赖服务
   systemctl status docker  # 如果使用容器

   # 检查配置文件
   python -c "import yaml; yaml.safe_load(open('actions/action.yml'))"

   # 检查端口占用
   netstat -tlnp | grep 8000
   ```

2. **启动服务**
   ```bash
   # 方式1：直接启动
   cd /projects/cuscli
   nohup python -m autocoder.chat_auto_coder > /tmp/auto-coder.out 2>&1 &

   # 方式2：使用systemd（推荐）
   systemctl start auto-coder

   # 方式3：使用supervisor
   supervisorctl start auto-coder
   ```

3. **启动验证**
   ```bash
   # 检查进程
   ps aux | grep auto-coder

   # 检查端口
   netstat -tlnp | grep auto-coder

   # 检查日志
   tail -f /home/$(whoami)/.auto-coder/logs/auto-coder.log

   # 功能测试
   python -m autocoder.chat_auto_coder --quick
   ```

4. **记录日志**
   - 启动时间
   - 启动人员
   - 启动原因
   - 验证结果

#### 3.2.2 服务停止

**标准停止流程：**

1. **停止前通知**
   - 提前通知用户
   - 检查当前任务
   - 选择合适时机

2. **优雅停止**
   ```bash
   # 方式1：使用systemd
   systemctl stop auto-coder

   # 方式2：发送SIGTERM
   kill -15 $(pgrep -f auto-coder)

   # 等待进程退出（最多30秒）
   for i in {1..30}; do
     pgrep -f auto-coder > /dev/null || break
     sleep 1
   done
   ```

3. **强制停止**（如优雅停止失败）
   ```bash
   # 发送SIGKILL
   kill -9 $(pgrep -f auto-coder)

   # 清理残留
   rm -f /tmp/auto-coder.pid
   ```

4. **停止验证**
   ```bash
   # 确认进程已退出
   ps aux | grep auto-coder

   # 确认端口已释放
   netstat -tlnp | grep 8000
   ```

#### 3.2.3 服务重启

**重启场景：**
- 配置文件修改后
- 系统资源异常
- 定期维护重启
- 故障恢复

**重启流程：**
```bash
# 使用systemd重启
systemctl restart auto-coder

# 或手动重启
systemctl stop auto-coder
sleep 5
systemctl start auto-coder

# 验证重启
systemctl status auto-coder
tail -f /home/$(whoami)/.auto-coder/logs/auto-coder.log
```

### 4.2 系统资源监控

#### 4.2.1 CPU监控

**监控指标：**
- CPU使用率（整体、各核心）
- CPU负载（1min、5min、15min）
- CPU等待时间（iowait、steal）

**告警阈值：**
| 级别 | CPU使用率 | 负载（1min） | 处理措施 |
|------|----------|-------------|----------|
| 警告 | >70% | >CPU核心数×0.7 | 关注，分析原因 |
| 严重 | >85% | >CPU核心数×1.5 | 立即处理，优化或扩容 |
| 紧急 | >95% | >CPU核心数×2.0 | 紧急扩容或限流 |

**监控命令：**
```bash
# 实时CPU使用
top -bn1 | grep "Cpu(s)"

# CPU详细信息
mpstat -P ALL 1 5

# 进程CPU排序
ps aux --sort=-%cpu | head -10
```

#### 4.2.2 内存监控

**监控指标：**
- 内存使用率
- 内存可用量
- Swap使用率
- 内存泄漏检测

**告警阈值：**
| 级别 | 内存使用率 | 可用内存 | Swap使用 | 处理措施 |
|------|----------|---------|---------|----------|
| 警告 | >75% | <2GB | >20% | 关注内存趋势 |
| 严重 | >85% | <1GB | >50% | 重启服务或扩容 |
| 紧急 | >95% | <500MB | >80% | 立即释放内存 |

**监控命令：**
```bash
# 内存使用概览
free -h

# 详细内存信息
cat /proc/meminfo

# 进程内存排序
ps aux --sort=-%mem | head -10

# 检查内存泄漏
while true; do
  ps -eo pid,cmd,%mem | grep auto-coder | grep -v grep
  sleep 60
done
```

#### 4.2.3 磁盘监控

**监控指标：**
- 磁盘使用率
- Inode使用率
- 磁盘IO性能
- 磁盘读写速率

**告警阈值：**
| 级别 | 磁盘使用率 | Inode使用 | 处理措施 |
|------|----------|----------|----------|
| 警告 | >75% | >75% | 清理日志，归档数据 |
| 严重 | >85% | >85% | 紧急清理或扩容 |
| 紧急 | >95% | >95% | 立即停止写入 |

**监控命令：**
```bash
# 磁盘空间
df -h

# Inode使用
df -i

# 磁盘IO统计
iostat -x 1 5

# 查找大文件
find /home -type f -size +100M -exec ls -lh {} \;

# 目录大小排序
du -h /home/$(whoami)/.auto-coder | sort -rh | head -20
```

#### 4.2.4 网络监控

**监控指标：**
- 网络流量（入站/出站）
- 连接数
- 网络错误率
- 响应时间

**监控命令：**
```bash
# 网络流量
iftop -t -s 10

# 连接统计
netstat -an | awk '/^tcp/ {print $6}' | sort | uniq -c

# 网络错误
netstat -i

# 检查连接数
netstat -an | grep ESTABLISHED | wc -l
```

### 4.3 应用监控

#### 4.3.1 进程监控

**监控内容：**
- 进程存活状态
- 进程资源占用
- 进程重启次数
- 进程运行时长

**监控脚本：**

```python
import time
import json
from datetime import datetime

class PerformanceMonitor:
    def __init__(self, log_file="/var/log/auto-coder-perf.log"):
        self.log_file = log_file

    def record_metric(self, metric_name, value, tags=None):
        entry = {
            "timestamp": datetime.now().isoformat(),
            "metric": metric_name,
            "value": value,
            "tags": tags or {}
        }
        with open(self.log_file, 'a') as f:
            f.write(json.dumps(entry) + '\n')

    def timer(self, operation_name):
        """上下文管理器，用于计时"""
        class Timer:
            def __init__(self, monitor, name):
                self.monitor = monitor
                self.name = name
                self.start = None

            def __enter__(self):
                self.start = time.time()
                return self

            def __exit__(self, *args):
                duration = time.time() - self.start
                self.monitor.record_metric(
                    f"{self.name}_duration",
                    duration,
                    {"operation": self.name}
                )

        return Timer(self, operation_name)

# 使用示例
monitor = PerformanceMonitor()

with monitor.timer("code_check"):
    # 执行代码检查
```

### 11.1 常用运维脚本

#### 11.1.1 健康检查脚本

```bash
#!/bin/bash
# health-check.sh
# 系统健康检查脚本

set -e

RED='\033[0;31m'
GREEN='\033[0;32m'
YELLOW='\033[1;33m'
NC='\033[0m' # No Color

echo "=== Auto-Coder 健康检查 ==="
echo "时间: $(date)"
echo

# 1. 进程检查
echo "1. 进程状态检查"
if pgrep -f auto-coder > /dev/null; then
    echo -e "${GREEN}✓ 进程运行正常${NC}"
else
    echo -e "${RED}✗ 进程未运行${NC}"
fi

# 2. CPU检查
echo "2. CPU使用率检查"
CPU_USAGE=$(top -bn1 | grep "Cpu(s)" | awk '{print $2}' | cut -d'%' -f1)
if (( $(echo "$CPU_USAGE < 70" | bc -l) )); then
    echo -e "${GREEN}✓ CPU使用率正常: ${CPU_USAGE}%${NC}"
elif (( $(echo "$CPU_USAGE < 85" | bc -l) )); then
    echo -e "${YELLOW}⚠ CPU使用率偏高: ${CPU_USAGE}%${NC}"
else
    echo -e "${RED}✗ CPU使用率过高: ${CPU_USAGE}%${NC}"
fi

# 3. 内存检查
echo "3. 内存使用检查"
MEM_USAGE=$(free | grep Mem | awk '{printf("%.2f", $3/$2 * 100.0)}')
if (( $(echo "$MEM_USAGE < 75" | bc -l) )); then
    echo -e "${GREEN}✓ 内存使用正常: ${MEM_USAGE}%${NC}"
elif (( $(echo "$MEM_USAGE < 85" | bc -l) )); then
    echo -e "${YELLOW}⚠ 内存使用偏高: ${MEM_USAGE}%${NC}"
else
    echo -e "${RED}✗ 内存使用过高: ${MEM_USAGE}%${NC}"
fi

# 4. 磁盘检查
echo "4. 磁盘空间检查"
DISK_USAGE=$(df -h / | tail -1 | awk '{print $5}' | cut -d'%' -f1)
if [ "$DISK_USAGE" -lt 75 ]; then
    echo -e "${GREEN}✓ 磁盘空间充足: ${DISK_USAGE}%${NC}"
elif [ "$DISK_USAGE" -lt 85 ]; then
    echo -e "${YELLOW}⚠ 磁盘空间偏紧: ${DISK_USAGE}%${NC}"
else
    echo -e "${RED}✗ 磁盘空间不足: ${DISK_USAGE}%${NC}"
fi

# 5. 日志错误检查
echo "5. 日志错误检查"
ERROR_COUNT=$(tail -1000 /home/$(whoami)/.auto-coder/logs/auto-coder.log 2>/dev/null | grep -c "ERROR" || echo 0)
if [ "$ERROR_COUNT" -eq 0 ]; then
    echo -e "${GREEN}✓ 无错误日志${NC}"
elif [ "$ERROR_COUNT" -lt 10 ]; then
    echo -e "${YELLOW}⚠ 发现少量错误: ${ERROR_COUNT}条${NC}"
else
    echo -e "${RED}✗ 错误较多: ${ERROR_COUNT}条${NC}"
fi

echo
echo "=== 健康检查完成 ==="
```

#### 11.1.2 一键部署脚本

```bash
#!/bin/bash
# deploy.sh
# Auto-Coder 一键部署脚本

set -e

echo "=== Auto-Coder 部署脚本 ==="

# 检查root权限
if [ "$EUID" -ne 0 ]; then
    echo "请使用root权限运行此脚本"
    exit 1
fi

# 1. 安装依赖
echo "1. 安装系统依赖..."
apt update
apt install -y python3 python3-pip git

# 2. 创建用户
echo "2. 创建运行用户..."
if ! id "autocoder" &>/dev/null; then
    useradd -r -m -s /bin/bash autocoder
fi

# 3. 部署代码
echo "3. 部署代码..."
INSTALL_DIR="/opt/auto-coder"
mkdir -p $INSTALL_DIR
cp -r /projects/cuscli/* $INSTALL_DIR/
chown -R autocoder:autocoder $INSTALL_DIR

# 4. 安装Python依赖
echo "4. 安装Python依赖..."
cd $INSTALL_DIR
pip3 install -r requirements.txt

# 5. 配置系统服务
echo "5. 配置systemd服务..."
cat > /etc/systemd/system/auto-coder.service <<EOF
[Unit]
Description=Auto-Coder Service
After=network.target

[Service]
Type=simple
User=autocoder
WorkingDirectory=$INSTALL_DIR
ExecStart=/usr/bin/python3 -m autocoder.chat_auto_coder
Restart=on-failure
RestartSec=10

[Install]
WantedBy=multi-user.target
EOF

systemctl daemon-reload
systemctl enable auto-coder

# 6. 配置日志轮转
echo "6. 配置日志轮转..."
cat > /etc/logrotate.d/auto-coder <<EOF
/home/*/.auto-coder/logs/*.log {
    daily
    rotate 30
    compress
    delaycompress
    missingok
    notifempty
}
EOF

echo "=== 部署完成 ==="
echo "启动服务: systemctl start auto-coder"
echo "查看状态: systemctl status auto-coder"
```
