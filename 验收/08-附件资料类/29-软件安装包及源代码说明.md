### 2.2 Wheel包格式说明

#### 2.2.1 什么是Wheel包

Wheel(.whl)是Python的标准二进制包格式,具有以下特点:

- ✅ **快速安装**: 预编译,无需构建,安装速度快
- ✅ **跨平台**: 纯Python包可在所有平台使用
- ✅ **标准化**: PEP 427标准,pip原生支持
- ✅ **元数据完整**: 包含版本、依赖、许可证等元数据
- ✅ **安全可靠**: 可签名验证,防篡改

#### 2.2.2 文件命名规范

```
cuscli-1.1.0-py3-none-any.whl
│      │     │   │    └─ 任何架构(纯Python)
│      │     │   └────── 不依赖特定平台
│      │     └────────── Python 3.x (3.10+)
│      └──────────────── 版本号 1.1.0
└─────────────────────── 包名 cuscli
```

### 2.4 安装包使用方法

#### 2.4.1 标准安装方法

**前提条件**:
- Python 3.10、3.11 或 3.12 已安装
- pip 工具已安装(通常随Python安装)
- 有网络连接(用于安装依赖)或准备好离线依赖包

**在线安装**:
```bash
# 1. 安装wheel包
pip install cuscli-1.1.0-py3-none-any.whl

# 2. 验证安装
auto-coder --version
chat-auto-coder --version

# 3. 查看安装位置
pip show cuscli
```

**离线安装**(内网环境):
```bash
# 1. 准备依赖包(在有网络的机器上)
pip download cuscli-1.1.0-py3-none-any.whl -d ./offline_packages

# 2. 拷贝offline_packages目录到内网机器

# 3. 离线安装
pip install --no-index --find-links=./offline_packages cuscli-1.1.0-py3-none-any.whl
```

详细安装步骤参见《系统部署手册》第3节。

#### 2.4.2 虚拟环境安装(推荐)

为避免与系统Python环境冲突,推荐在虚拟环境中安装:

```bash
# 使用venv
python3 -m venv /opt/cuscli-env
source /opt/cuscli-env/bin/activate  # Linux/macOS
# 或 call \opt\cuscli-env\Scripts\activate.bat  # Windows
pip install cuscli-1.1.0-py3-none-any.whl

# 使用conda
conda create -n cuscli python=3.10 -y
conda activate cuscli
pip install cuscli-1.1.0-py3-none-any.whl
```

#### 2.4.3 升级与卸载

**升级**:
```bash
# 升级到新版本
pip install --upgrade cuscli-1.1.0-py3-none-any.whl
```

**卸载**:
```bash
# 卸载软件
pip uninstall cuscli -y

# 验证已卸载
pip show cuscli  # 应提示未找到
```

## 7. 版本信息

### 7.1 版本号说明

**版本号**: `1.1.0`

**版本格式**: `主版本号.次版本号.修订号` (Semantic Versioning)

- **主版本号 (1)**: 重大架构变更或不兼容更新
- **次版本号 (1)**: 新功能添加,向下兼容
- **修订号 (0)**: Bug修复,小改进

## 9. 从源码构建

### 9.1 构建环境要求

| 环境组件 | 版本要求 |
|---------|---------|
| Python | 3.10 - 3.12 |
| pip | >= 21.0 |
| setuptools | >= 60.0 |
| wheel | >= 0.37 |
| build | >= 0.7 |

### 9.2 构建步骤

#### 9.2.1 准备环境

```bash
# 1. 克隆或解压源代码
cd /projects/cuscli

# 2. 创建虚拟环境
python3 -m venv build-env
source build-env/bin/activate

# 3. 安装构建工具
pip install --upgrade pip setuptools wheel build
```

#### 9.2.2 构建Wheel包

```bash
# 使用 build 工具(推荐)
python -m build --wheel

# 或使用 setup.py
python setup.py bdist_wheel

# 生成的wheel包在 dist/ 目录
ls -lh dist/cuscli-1.1.0-py3-none-any.whl
```

#### 9.2.3 验证构建结果

```bash
# 1. 检查wheel包内容
unzip -l dist/cuscli-1.1.0-py3-none-any.whl | head -20

# 2. 测试安装
pip install dist/cuscli-1.1.0-py3-none-any.whl

# 3. 运行测试
auto-coder --help
```

### 9.3 构建脚本

提供了自动化构建脚本:

**scripts/build_wheel.sh** (Linux/macOS):
```bash
#!/bin/bash
# 自动化构建脚本
cd "$(dirname "$0")/.."
python -m build --wheel
echo "Build completed: dist/cuscli-1.1.0-py3-none-any.whl"
```

使用方法:
```bash
chmod +x scripts/build_wheel.sh
./scripts/build_wheel.sh
```
