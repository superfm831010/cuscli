## 1. 概述

### 1.1 编写目的

本文档旨在说明 **Cuscli AI 编程助手平台 v1.1.0** 在国产化环境下的适配情况、支持范围、部署方案及验证结果,为黄埔海关在国产化硬件和软件环境下的应用部署提供技术参考。

### 1.2 适用范围

本文档适用于以下场景:
- 黄埔海关信息化系统国产化改造项目
- 国产服务器、国产操作系统环境部署
- 国产数据库适配需求
- 信创工程相关技术评估

### 1.3 国产化背景

根据《关于加强国产化替代工作的指导意见》和海关总署信息化国产化替代要求,本项目在设计和实施过程中充分考虑国产化环境的适配性,确保系统在国产化平台上稳定运行。

### 1.4 国产化原则

1. **兼容性优先**: 优先选择跨平台、标准化的技术栈
2. **验证充分**: 所有声明支持的环境均经过实际测试验证
3. **风险可控**: 明确标注未验证环境,提供风险评估
4. **文档完整**: 提供详细的适配说明和操作指南
5. **持续支持**: 质保期内提供国产化环境技术支持

### 2.2 技术栈国产化分析

#### 2.2.1 Python 跨平台特性

Cuscli 平台基于 **Python 3.10-3.12** 开发,Python 作为跨平台解释型语言,具有以下国产化优势:

- ✅ **平台无关性**: 无需修改代码即可在各类国产系统上运行
- ✅ **标准化**: 遵循国际标准,与底层硬件解耦
- ✅ **生态成熟**: 依赖的第三方库均为开源软件,国产系统普遍支持
- ✅ **社区支持**: Python 在国产化环境的应用案例丰富

#### 2.2.2 依赖组件国产化兼容性

本系统依赖的 68 个第三方 Python 库均为开源软件,在国产化环境中的兼容性如下:

| 依赖类型 | 数量 | 国产化兼容性 | 说明 |
|---------|------|-------------|------|
| 纯Python库 | 52个 | ✅ 完全兼容 | 无平台依赖 |
| 包含C扩展的库 | 16个 | ✅ 完全兼容 | 支持x86/ARM编译 |
| 外部服务依赖 | 0个 | ✅ 无依赖 | 无外部系统依赖 |

**重要说明**: 所有依赖库均可通过 pip 从 PyPI 仓库安装,或在离线环境下通过 wheel 包安装。

### 2.3 国产化适配验证方法

所有国产化适配验证均遵循以下标准流程:

1. **环境搭建**: 在目标国产化平台上搭建标准运行环境
2. **功能测试**: 执行完整的功能测试用例（见《系统测试报告》）
3. **性能测试**: 进行性能基准测试,与标准环境对比
4. **稳定性测试**: 7×24小时稳定性运行测试
5. **问题记录**: 详细记录兼容性问题及解决方案
6. **文档归档**: 形成验证报告并归档

### 11.2 问题详情与解决方案

#### 11.2.1 GZ-001: 麒麟系统Python 3.6过旧

**问题描述**:
- 中标麒麟V7.0 默认Python版本为3.6,低于系统要求的3.10

**影响范围**:
- 中标麒麟V7.0及更旧版本

**解决方案**:
```bash
# 方案1: 使用conda安装Python 3.10 (推荐)
wget https://repo.anaconda.com/miniconda/Miniconda3-latest-Linux-x86_64.sh
bash Miniconda3-latest-Linux-x86_64.sh -b -p $HOME/miniconda3
source ~/miniconda3/bin/activate
conda create -n autocoder python=3.10 -y
conda activate autocoder

# 方案2: 从源码编译Python 3.10 (参考《系统部署手册》)
```

**验证方法**:
```bash
python --version  # 应输出 Python 3.10.x
```

**状态**: ✅ 已解决,提供详细部署文档

#### 11.2.2 GZ-002: 部分C扩展库ARM编译慢

**问题描述**:
- 在ARM平台首次安装时,部分C扩展库(如numpy、lxml)需要编译,耗时较长(5-10分钟)

**影响范围**:
- 鲲鹏、飞腾等ARM芯片平台

**解决方案**:
```bash
# 方案1: 使用conda预编译包 (推荐)
conda install numpy lxml matplotlib -y

# 方案2: 使用manylinux wheel包
pip install --prefer-binary numpy lxml matplotlib

# 方案3: 制作离线安装包,包含预编译wheel
# 参见《内网环境部署方案》第6节
```

**状态**: ✅ 已解决,提供预编译包

#### 11.2.3 GZ-003: 终端中文显示问题

**问题描述**:
- 旧版国产操作系统默认locale配置可能导致中文显示乱码

**影响范围**:
- 中标麒麟V7.0及更旧版本
- 部分精简版国产系统

**解决方案**:
```bash
# 1. 检查locale
locale

# 2. 设置中文locale
export LANG=zh_CN.UTF-8
export LC_ALL=zh_CN.UTF-8

# 3. 写入.bashrc永久生效
echo 'export LANG=zh_CN.UTF-8' >> ~/.bashrc
echo 'export LC_ALL=zh_CN.UTF-8' >> ~/.bashrc
source ~/.bashrc
```

**验证方法**:
```bash
auto-coder --help  # 检查中文帮助信息显示是否正常
```

**状态**: ✅ 已解决,已写入部署文档
