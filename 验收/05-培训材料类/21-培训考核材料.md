## 1. 考核说明

### 1.1 考核目的

通过考核评估培训效果，确保学员：
- 掌握平台的核心功能和操作方法
- 能够在实际工作中正确使用平台
- 了解常见问题的解决方法
- 具备独立工作的能力

### 1.2 考核形式

**理论知识测试**：
- 形式：笔试或在线测试
- 时长：建议30-45分钟
- 题型：单选、多选、判断、简答
- 分值：100分

**实操技能考核**：
- 形式：上机操作
- 时长：建议60-90分钟
- 内容：完成指定任务
- 分值：100分

### 1.3 考核标准

**合格标准**：
- 理论知识：≥60分
- 实操技能：≥60分
- 综合成绩：（理论×40% + 实操×60%）≥60分

**优秀标准**：
- 理论知识：≥85分
- 实操技能：≥85分
- 综合成绩：（理论×40% + 实操×60%）≥85分

### 1.4 补考说明

未通过考核的学员，建议：
- 复习培训材料和手册
- 参加补充培训或辅导
- 在1周内参加补考
- 补考次数建议不超过2次

34. **问题**：如何配置内网环境的代理服务器？

    **参考答案**：

    - 格式：http://proxy.company.com:port
    - 可以在系统级或用户级配置
    - 配置文件中也可指定代理
    - 验证代理是否生效

    示例：
    ```bash
    export HTTP_PROXY=http://proxy.example.com:8080
    export HTTPS_PROXY=http://proxy.example.com:8080
    ```

    **评分要点**（5分）：
    - 提及环境变量（2分）
    - 格式正确（1分）
